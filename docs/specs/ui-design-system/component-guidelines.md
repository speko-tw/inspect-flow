# 前端元件規範與使用指引

本文件收斂 T10 元件規範，實作以 `frontend/src/components/`、`frontend/src/components/forms/`、`frontend/src/components/layout/` 為準。功能規則及資料契約仍由各功能規格負責；本文件不新增 API 或授權規則。

## 使用原則

- 先依工作流程選版面：可掃描的資料用清單；選定項目的內容用詳情；建立與修改使用清楚分開的表單入口。桌機可並列清單和詳情，手機採清單到詳情的逐層瀏覽。
- 使用共用語意 token 表達頁面、表面、文字、邊界、焦點、選取、狀態、間距、圓角、陰影、字型與動態。元件及頁面不得複製另一套色票。
- 一頁最多一個醒目的主要操作。次要和破壞性操作採相符層級；破壞性動作先說明對象和後果，取消不得送出。
- 狀態以文字、形狀或圖示共同傳達，不單靠顏色。只有實際可互動的元件才需要互動狀態。
- 表單欄位有標籤、必填狀態、說明和欄旁錯誤；錯誤摘要可導向欄位。送出中保留輸入並防止重複提交。
- 窄螢幕保留中文短詞，不在詞中斷行；長說明自然換行。主要操作宜至少 44×44 CSS px；若版面限制而縮小，保留間距並以實際操作驗證。
- 動態效果應尊重 `prefers-reduced-motion`。外觀選擇器及跨裝置偏好依 #515 契約完成後再驗收，本文件不推定偏好 API。

## 共用元件

| 元件 | 使用時機 | 狀態和可及性 |
|---|---|---|
| `Button` | 觸發動作；依主要、次要、一般或破壞性分級 | 保留原生按鈕語意；需要時呈現 focus-visible、disabled、loading；操作結果由狀態訊息回饋 |
| `IconButton` | 只有圖示的操作 | 必須提供可及名稱；焦點、停用及非同步狀態依實際操作呈現 |
| `Field`、`Input` | 表單控制項及其標籤、說明、錯誤 | 標籤關聯控制項；錯誤有文字且可定位；鍵盤焦點清楚 |
| `Badge` | 簡短狀態標示 | 靜態標示不偽裝成按鈕，狀態不只以色彩傳達 |
| `Tag` | 分類或中性標記 | 靜態使用時不要求互動狀態 |
| `Card` | 有清楚分組或摘要的區塊 | 靜態卡片不暗示可點；可互動時由語意控制項承擔焦點與選取狀態 |
| `InfoRow`、`StatCard` | 詳情欄位與摘要數值 | 文字標籤和數值可讀；不以顏色作唯一區別 |
| `SectionHeader` | 區分頁面內容章節 | 標題層級連續；內含控制項時由控制項負責互動狀態 |
| `FormPatterns` | 新增／修改、摘要錯誤、送出生命週期、確認 | IME 組字期間不誤送；同步例外與非同步拒絕不可假報成功；取消確認不送出 |
| `LayoutPatterns` | 清單／詳情、窄螢幕逐層版面、狀態區塊 | 360px 下無水平溢位；保留上下文與下一步；空、載入、失敗狀態有可理解文字 |

## 元件狀態矩陣

| 類別 | hover／pressed | focus-visible | selected | loading | success／error | disabled |
|---|---|---|---|---|---|---|
| Button、IconButton | 可操作時 | 必須 | 僅選項型控制項 | 非同步操作時 | 關聯訊息呈現 | 不可操作時 |
| Input、Select、Textarea | 依原生互動 | 必須 | 選項控制項 | 僅非同步驗證 | 欄位錯誤及驗證訊息 | 不可編輯時 |
| 欄位、錯誤摘要 | 含連結時 | 含可操作連結時 | 不適用 | 由表單呈現 | 可定位文字錯誤 | 不適用 |
| Badge、Tag、SectionHeader | 不適用 | 不適用 | 不適用 | 不適用 | 僅承載狀態文字時 | 不適用 |
| 靜態 Card、InfoRow、StatCard、Callout | 不適用 | 不適用 | 不適用 | 不適用 | 只在承載狀態訊息時 | 不適用 |
| 互動 Card／InfoRow | 可操作時 | 必須 | 可選取時 | 非同步開啟時 | 關聯訊息呈現 | 不可操作時 |
| 確認流程 | 僅控制項適用 | 控制項必須；初始焦點依風險 | 不適用 | 非同步確認時 | 關聯訊息呈現 | 不可操作時 |

## 各頁套用範圍

依實際前端入口、共用元件引用與畫面走查盤點；頁面專用版面仍可保留，但語意色、焦點、表單錯誤和互動狀態應沿用共用規則。

| 功能區 | 主要入口／檔案 | 共用規範採用情形 |
|---|---|---|
| 帳號、公司、角色 | `admin/people/PeoplePage.tsx`、`admin/roles/RolesPage.tsx`、`admin/companies/` | 清單、詳情、表單、按鈕與狀態語彙 |
| 專案與成員 | `admin/projects/` | 專案清單與首頁摘要使用 DOM-R77 API 的 `member_count`；成員詳情區分已停用與已到期帳號，兩者採灰階樣式 |
| 權限與委派 | `admin/module-permissions/ModulePermissionsPage.tsx` | 欄位、診斷回饋、選擇控制項及確認流程 |
| 總覽與唯讀任務 | `admin/dashboard/` | 進度清單、狀態、唯讀任務明細與窄螢幕資訊層級 |
| 現場任務 | `field/` | 任務清單、任務詳情、逐步操作與狀態辨識 |
| 範本 | `admin/templates/`、專案查核項目頁 | 清單、詳情、表單及套用動作按權限呈現 |
| 個人設定與登入 | `auth/`、`settings/` | 共用表單及回饋；跨裝置外觀偏好待 #515 契約 |

## 設計系統回饋交付
