## 六個常用詞

| 畫面用詞 | 說明 |
|---|---|
| 帳號 | 登入系統的身分，可啟用或停用。 |
| 專案 | 一項工程查核工作。 |
| 成員 | 加入某個專案的帳號。 |
| 角色 | 成員在某個專案裡可以做的事。 |
| 權限 | 帳號在公司範圍可以使用的功能。 |
| 任務 | 指派給現場執行的一項查核工作。 |

帳號權限與專案角色分開設定。有權限不代表已能在某個專案操作；帳號也要加入該專案並取得合適的角色。

## 導覽

```text
總覽 ｜ 任務 ｜ 專案 ｜ 範本 ｜ 管理▾
                                      ├ 帳號
                                      ├ 公司
                                      ├ 角色
                                      └ 紀錄
```

只顯示帳號可使用的導覽項目，順序固定。「範本」提供給系統管理者及有管理範本庫權限者。範本使用者若有可編輯查核項目的專案角色，可從該專案的查核項目頁套用範本。

登入落點依帳號能力決定。沒有開通功能的帳號進入個人設定，畫面說明尚未開通功能；委派者若只有帳號管理範圍，直接看到「帳號」。更多帳號情境及操作步驟見[七個現場故事](accounts-and-permissions.md)。
