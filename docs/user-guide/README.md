# 使用指南

本指南依 #704、#705 核可的導覽與用詞整理；兩項工作合併前，這些內容是
核可目標，不代表已在正式畫面實測。截圖和未確認的畫面細節會在各故事中
標出，待正式頁面完成後補齊。

## 目錄

- [帳號與權限：七個現場故事](accounts-and-permissions.md)

## 先認識六個詞

| 畫面用詞 | 這裡代表什麼 |
|---|---|
| 帳號 | 登入系統的身分。帳號可被啟用或停用。 |
| 專案 | 一項工程查核工作。 |
| 成員 | 加入某個專案的帳號。 |
| 角色 | 成員在某個專案裡可以做的事。 |
| 權限 | 帳號在全公司可以使用的功能。 |
| 任務 | 指派給現場執行的一項查核工作。 |

帳號的權限與專案角色是兩層設定：有權限不代表已能在某個專案操作；
帳號還要成為該專案的成員，並取得合適的角色。

## 導覽列圖解

```text
主導覽（固定順序；只顯示有權限的項目）
總覽 ｜ 任務 ｜ 專案 ｜ 範本 ｜ 管理▾
                                      ├ 帳號
                                      ├ 公司
                                      ├ 角色
                                      └ 紀錄
右上角：設定 ｜ 登出
```

「範本」導覽只提供給有「管理範本庫」權限或系統管理者。內業工程師可在
有編輯查核項目角色的專案內套用範本，但導覽不會出現「範本」（#705 後生效）。

登入後會依帳號權限前往可用的入口。委派者若只有「帳號」，導覽直接顯示
「帳號」連結，不另外顯示「管理▾」。沒有開通功能的帳號會到「設定」，
並看到「尚未開通任何功能，請洽系統管理者」。每個帳號只看到可使用的
導覽項目，位置順序不變。

## 我是誰、登入會看到什麼

下表以示範資料的帳號說明各身分的核可目標。`demo-manager` 尚未加入專案，
因此示範情境只列「總覽」；若主管也有專案權限並成為成員，才會看到
「專案」。

| 身分與示範帳號 | 登入落點 | 可見導覽 | 使用範圍 |
|---|---|---|---|
| 系統管理者 `admin` | 總覽 | 總覽、任務、專案、範本、管理▾（帳號、公司、角色、紀錄） | 管理帳號、公司、角色、權限與紀錄；可查看所有專案。 |
| 主管 `demo-manager` | 總覽 | 總覽；成為專案成員且有權限時再顯示專案 | 查看專案進度、任務狀態、地點與指派；看不到照片和查核結果。 |
| 內業工程師 `demo-office` | 專案 | 專案、任務（有查核權限時） | 管理有權限的專案工作；可在專案查核項目頁套用範本，不會看到範本導覽。 |
| 現場工程師 `demo-field-a` | 任務 | 任務 | 查看指派給自己的任務並開始查核；可由右上「設定」管理個人設定。 |
| 範本管理者 `demo-template-manager` | 範本 | 範本及其他已開通項目 | 管理查核範本；專案內能做什麼仍看該專案角色。 |
| 委派者 `demo-template-delegate` | 帳號 | 帳號（直接連結，沒有管理▾） | 只替他人開通或收回受委派範圍內的權限；不能替自己授權、建立帳號或編輯範本。 |
| 外部協作 `demo-consultant` | 專案 | 專案 | 唯讀查看已加入的專案；看不到套用範本的按鈕，也不會看到範本導覽。 |
| 尚未開通功能 `demo-no-access` | 設定 | 沒有主導覽項目 | 看到尚未開通功能的說明，不會遇到無法繼續的空頁。 |

右上角另有「設定」與「登出」。外部協作的專案內容維持唯讀；有
`template.use` 仍不足以套用範本，還需要該專案中可編輯查核項目的角色。
系統管理者不受上述一般專案限制。
