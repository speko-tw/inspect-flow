# Issue #633：非同步焦點斷言穩定化

狀態：實作與本機驗收完成；尚未建立 PR。

## 來源與根因

- 分支：`633-stabilize-zone-focus-test`
- 驗收來源 HEAD：`4a2749d14276d320f1b1e9544f2cf21f42397e61`
- 根因：表單錯誤或確認框先 render，焦點則由 passive effect 設定。測試只等待錯誤文字／ARIA 狀態出現，隨即同步斷言焦點；在 effect 尚未執行時會觀察到 `document.body`，造成競態。
- 原始失敗證據：未修改來源的 `make check` 在 SaveErrorFocus 測試重現同型失敗；錯誤文字與 ARIA 已存在，但 alert 尚未取得焦點。該次完整檢查有失敗，不能視為通過。

- `frontend/src/admin/planning/ProjectZonesPage.test.tsx`：分區新增／改名錯誤焦點、改名初始焦點、刪除確認框初始焦點與取消後焦點返回。
