# 權限管理原型操作導覽

此版本以「職務起手式」作為新增人員的主要入口。互動資料只存在瀏覽器
記憶體，不會連線或寫入實際資料；頁面用詞以日常工作為主，權限碼只出現
在進階區或補充小字。

## 主要流程

1. **身分**：選內部人員或外部協作人員，並填姓名。外部身分後續只能選
   「外包顧問」。
2. **職務**：依身分選系統管理、內業規劃、現場查核或外包顧問。
3. **專案**：可選目前要加入的專案，也可略過。
4. **預覽與確認**：先看「可以做／不能做」，小字列出既有權限組合和預設
   專案角色；確認後建立示意人員並套用。

人員頁先顯示「目前可以做什麼」。若缺少常見授權層，頁面說明缺少的模組
權限或專案角色，並提供只補該層的操作。進階逐項權限清冊預設收合。
「權限檢查」可選人員與動作，說明缺少的層級並示意補足方式。

## 六個情境故事與場景

| 故事 | 場景 | 展示重點 |
| --- | --- | --- |
| 新人報到：用職務起手式開始 | 先選身分，再說明職務；可略過專案，先看白話預覽 | 內部新人精靈、職務組合、白話預覽與確認 |
| 外包顧問：先看能做與不能做 | 外部身分只提供外包顧問；預覽限制並選擇專案 | 外部職務限制、外部可用角色與範圍 |
| 看不到任務：查出少了哪一層 | 選人與動作，直接查原因；補上專案角色，確認結果通過 | 補權後結果即時更新；區分模組權限與專案角色、逐層補足 |
| 委派同事：把工作交出去但守住邊界 | 從進階設定選林沐青為範本委派者；委派者不能替自己或轉授權；收回委派不移除既有權限 | 委派在進階操作、不可自授／轉委派、撤銷影響 |
| 少一層就補一層：不重做整套設定 | 用白話摘要看目前能力；一鍵補上缺少的專案角色 | 能力摘要、缺項提示與局部修復 |
| 進階設定：四道防線各自守住一層 | 建立者角色要求；可指派與外部可用分開核准；專案角色不能自行升級；組合越權整組拒絕 | 角色、委派和組合維護留在收合的進階設定 |

每個場景均呈現「現場故事」、「請你這樣操作」和「為什麼這樣設計」。
底部故事導覽會切換對應身分、頁面和預設狀態；進入不同故事時會重設示意資料，讓逐個瀏覽與連續播放得到一致的起始狀態。

## 視覺與互動規則

- 保留跟隨系統、淺色、深色三段主題切換；淺／深色樣式使用 `:root`
  色彩變數，頁面背景明確指定。
- 桌面使用導覽側欄與工作區；窄螢幕改為堆疊配置。目標支援 360px
  手機寬度，不應出現頁面水平捲動。
- 權限清冊、模組委派、組合維護、角色核准與建立者角色都收在進階設定。
- 原型沒有使用瀏覽器 `alert()` 或 `confirm()`；需要確認時使用頁面內狀態。
- 姓名、公司與專案皆為虛構示意資料。原型不代表 API、持久化、後端拒絕
  或稽核流程已實作。
