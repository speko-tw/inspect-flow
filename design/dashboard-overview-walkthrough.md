# Dashboard 總覽與工程師工作量原型走查

**狀態：** 待負責人親手操作並核可；這不是正式頁面或入口。

## 視覺方向

- 依 2026-10-16 核可原型採頁首品牌海軍藍 `#002060`、金色細底線
  `#ffc200`；淺色互動主色 `#002060`，深色互動主色 `#8cc4ff` 搭配深色文字。
- 頁面、表面、文字、邊界、狀態與焦點沿用正式 tokens 語意。所有顏色
  集中定義為 `:root` CSS 變數；深色映射同時支援 `data-theme="dark"`
  與 `prefers-color-scheme: dark`，也可用按鈕在跟隨系統、淺色、深色間切換。
- 桌面以頁首分頁切換「專案進度／工程師工作量」，兩者共用一個範圍選擇器。
  讓管理者在同一上下文檢查整體進度及各人員歸屬，避免複製兩個彼此脫節的
  Dashboard 或重複範圍控制。
- 桌面以清單比較專案或工程師；360px 改卡片呈現每筆指標，避免把桌機表格
  壓縮成難讀的窄欄。

## 示意資料與資料來源

- 所有畫面數字與人員都是瀏覽器記憶體內的示意資料，頁首與各列均標示
  「示意資料」；原型不呼叫 API。
- 正式專案摘要／清單由 #408 summary/projects API 提供。前端只格式化
  response，不自行加總或推算。
- 工程師清單使用 #408 engineers API 欄位：`user_id`、`username`、
  `name_zh`、`assigned_pending_count`、`assigned_in_progress_count`、
  `started_in_progress_count`、`completed_by_count`。查詢支援
  `project_id`、`q`、`cursor`、`limit`。
- 四種計數分開呈現；同一人可同時是指派者、開始者與完成者，數字不是互斥
  分組，不可加總成「總人數」。原型的人員計數明確使用每個範圍的固定樣本值，
  不從其他欄位計算。
- ADM-R06 規定單一專案採呼叫者具備的專案進度／工作量範圍；全部專案需
  `all_project_progress.read` 或 Admin。依 #410 留言對照 #538/PR #544，
  工程師總覽採相同專案範圍；原型不判斷或擴張權限。畫面只顯示進度數字及
  工作量，不含照片與查核結果。

## 桌機走查（1280px）

1. 頁面初始為「專案進度」。確認頁首品牌藍、金線、示意資料標示與 API
   說明清楚，摘要不把待開始／進行中／完成數加總。
2. 切到「工程師工作量」。核對欄位分別為派任待開始、派任進行中、開始者
   進行中、完成查核；閱讀提示，確認不同人員歸屬可能重疊，不能相加為人數。
3. 在工程師檢視選「西側管線更新工程」，核對列內數字切換到該專案樣本，
   且沒有其他專案的無關人員；再切回「全部可查看專案」。
4. 搜尋「陳」，確認只顯示符合的工程師；搜尋不存在的字串，確認空狀態、
   清除搜尋後列表恢復。按「載入更多工程師」確認第四位出現。
5. 回到「專案進度」，按「載入更多專案」，搜尋「西側」，再切換單一專案。
   確認摘要、清單和搜尋都使用同一範圍，單一專案時分頁按鈕隱藏。
6. 選「模擬載入／空資料／錯誤」，確認狀態訊息明確、重試能回到示意資料，
   清除搜尋能回復列表。
7. 用頁首主題按鈕循環切換系統、淺色、深色；確認主色、表面、文字、邊界、
   狀態色和焦點在兩種主題皆可辨識。也可在瀏覽器中明確設定
   `document.documentElement.dataset.theme` 為 `light` 或 `dark`。

## 手機走查（360px）

8. 將 viewport 設為 360px，確認 `scrollWidth` 不超過 viewport 寬度；頁首
   分頁可以水平操作，頁面本體不產生水平捲動。
9. 分別切換專案進度與工程師工作量。確認摘要仍易讀，工程師每張列卡在
   姓名下方顯示四個有標籤的數字，沒有依賴桌面表頭。
10. 在工程師頁選單一專案與搜尋條件，確認人員範圍與數字同步切換；清除
    搜尋後可恢復。檢查完成查核與派任數字標籤沒有互相混淆。
11. 切換淺／深主題，確認 360px 文字、控制項、聚焦框與空／錯誤提示都在
    畫面內且可辨識。

## 鍵盤與狀態走查

12. 以 Tab 移動至分頁、範圍選單、搜尋及狀態控制；以左右方向鍵切換分頁。
    確認焦點樣式清楚且焦點所在分頁與內容一致。
13. 以鍵盤執行清除搜尋、載入更多與錯誤重試。確認狀態以 `role=status` 或
    `role=alert` 呈現，不使用 `alert()`／`confirm()`。

## 試用後需核可

請負責人親手走過兩種視圖、單一／全部範圍、淺深主題與 360px 走查，核可
資訊層級、範圍語意及工程師數字歸屬。核可前不開始正式頁面及導覽入口。
